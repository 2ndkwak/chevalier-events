Every guest tastes the same wines in the same order, so this is one list for the whole event -- not per guest. Uploading a new file replaces the current list.

Download CSV template

Columns: position, course, vintage (optional), domain, appellation, color (optional). Position is the wine's order within its own course and resets back to 1 for each new course -- e.g. the 1st and 2nd wines of course 1 are position 1 and 2, then the 1st wine of course 2 is position 1 again. That combination prints right on the tag as "position/course" (e.g. "2/1" = 2nd wine of course 1).

Appellation is printed as-is below the hole on the wine tag -- put anything you want there (e.g. "Premier Cru, Les Cabottes"), it wraps automatically.

Color ("red" or "white", optional) prints that wine in burgundy on the menu booklet's wine list, matching your usual convention. Leave blank for wines you don't need colored.

Setting a course's heading for the menu booklet (e.g. "Cocktails", "Premier Assiette") is done on the Menu page, not here.

Course numbering: 0 = Cocktails, 1 = Premier Assiette, 2 = Deuxieme, 3 = Troisieme, 4 = Fromages -- matches the French ordinals exactly, so the course number always tells you which course it is. Use the same numbers on the Menu page so wines and dishes line up.
